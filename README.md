# WhatsApp Leads Sync → Base44

כלי פרטי קטן (userscript ל-Tampermonkey) שרץ על **WhatsApp Web** וקורא לידים שתויגו
ידנית תחת תגית מסוימת, ושולח כל ליד חדש ל-CRM שב-Base44.

> ⚠️ הכלי הוא **READ-ONLY מוחלט**: הוא לא שולח הודעות, לא יוצר ולא משנה תגיות.
> הוא רק *קורא* את רשימת הצ'אטים והתגיות. סנכרון קורה **בלחיצה בלבד**.

---

## מה הכלי עושה

- רץ רק על `https://web.whatsapp.com/*`.
- קורא את הצ'אטים שתחת תגית מסוימת (ברירת מחדל: **"לידים חדשים לטיפול"**).
- לכל ליד חדש שולח בקשת `POST` ל-endpoint ב-Base44 (הסינון/האיחוד הסופי קורה בשרת).
- מוסיף כפתור צף **"סנכרן לידים"** (בפינה התחתונה, RTL) שמסנכרן בלחיצה.
- שומר רשימת טלפונים שכבר נשלחו (dedup קל מקומי) כדי להפחית רעש.

---

## Step 0 — בדיקת קונסול לפני שימוש ראשון (חשוב!)

הדרך שבה wa-js מחזיק את תגיות הצ'אט **משתנה בין גרסאות**. לפני שמסתמכים על הסקריפט,
מאמתים את המבנה בגרסה שלך:

1. התקן את הסקריפט (ראה "התקנה" למטה) ופתח את `web.whatsapp.com`.
2. פתח את ה-DevTools (F12) → לשונית **Console**.
3. הרץ:
   ```js
   Object.keys(WPP.labels).sort()
   ```
   ודא שקיימת `getAllLabels`. הרץ גם:
   ```js
   (await WPP.labels.getAllLabels()).map(l => ({ id: l.id, name: l.name }))
   ```
   כך תראה את ה-id ושם של כל תגית.
4. בדוק איך נראה צ'אט בודד שתייגת, כדי לראות **איפה יושבות התגיות שלו**:
   ```js
   const c = (await WPP.chat.list()).find(x => x.name);  // בחר צ'אט עם שם
   console.log(Object.keys(c));   // חפש שדה כמו labels
   console.log(c.labels);         // המבנה בפועל של התגיות בצ'אט
   ```
5. אם הסנכרון מחזיר 0 לידים למרות שתגית קיימת — סימן שמבנה התגיות שונה אצלך.
   במקרה כזה התאם את הפונקציה `chatHasLabel(...)` בקובץ `whatsapp-leads-sync.user.js`
   (היא מסומנת ב-`TODO`).

## התקנה (לחבר)

1. התקן את התוסף **Tampermonkey** לדפדפן (Chrome / Edge / Firefox).
2. פתח את לינק ההתקנה — Tampermonkey יזהה אותו אוטומטית ויציע "Install":
   ```
   https://raw.githubusercontent.com/strugo7/whatsapp-leads-sync/main/whatsapp-leads-sync.user.js
   ```
3. אשר את ההתקנה.
4. פתח את תפריט Tampermonkey (אייקון התוסף) → על דף WhatsApp Web תראה פקודה
   **"הגדרות חיבור ל-CRM"**. לחץ עליה והזן:
   - **כתובת ה-Webhook** של ה-CRM ב-Base44 (URL מלא).
   - **הסוד המשותף** (`x-api-key`) — נשמר מקומית בלבד, לא בקוד ולא בריפו.
   - **שם התגית** לסנכרון (אם שונה מברירת המחדל).
5. פתח `web.whatsapp.com`, ותראה כפתור צף **"סנכרן לידים"** בפינה התחתונה.

## מצב DRY_RUN (ברירת מחדל: פעיל)

כברירת מחדל הכלי במצב **DRY_RUN** — הוא **לא שולח כלום**, אלא רק מדפיס טבלה
(`console.table`) של הלידים החדשים שהיה שולח. כך אפשר לוודא שהזיהוי עובד נכון
לפני שמתחברים באמת.

להחלפה לשליחה אמיתית: תפריט Tampermonkey → **"מצב הרצה (DRY_RUN / שליחה אמיתית)"**.

---

## איך מתעדכן אוטומטית

ב-header של הסקריפט מוגדרים `@updateURL` ו-`@downloadURL` שמצביעים על ה-raw URL
ב-GitHub. Tampermonkey בודק עדכונים אוטומטית ומציע להתקין גרסה חדשה כש-`@version`
עולה. **ההגדרות שלך (URL, סוד, תגית) נשמרות ב-GM storage ולא נדרסות בעדכון.**

---

## הערת אבטחה

- הכלי **READ-ONLY** — הוא לא כותב כלום ל-WhatsApp, מה שמקטין משמעותית את הסיכון
  למספר של החבר.
- עם זאת, שימוש בכלי **לא-רשמי** מול WhatsApp Web הוא **הפרת תנאי השימוש (ToS)**
  של WhatsApp. בשימוש read-only ובקצב אנושי הסיכון נמוך — **אך לא אפס**.
- אין סודות בקוד עצמו: כל הקונפיגורציה הרגישה נשמרת מקומית בדפדפן דרך GM storage.

---

## פרטיות — איך מטופלים מספרי הטלפון

הכלי בנוי כך שמספרי טלפון **לא נשמרים ולא דולפים** למשטחים מקומיים:

| משטח | מה קורה |
|------|---------|
| **Console** | מודפס רק טלפון **ממוסך** (למשל `+972***67`) ב-DRY_RUN ובהודעות שגיאה. אף פעם לא המספר המלא. |
| **GM storage (dedup)** | נשמר רק **SHA-256** של הטלפון (עם salt אקראי פר-התקנה), אף פעם לא הטלפון עצמו. |
| **Network** | הטלפון נשלח **רק** ל-Webhook המוגדר, **רק מעל HTTPS** (מוצפן בתעבורה). אם ה-URL אינו HTTPS — השליחה נחסמת. גוף התשובה מהשרת **לא** נכתב לקונסול (כדי לא להחזיר טלפון בטעות). |
| **Cookies** | הכלי לא קורא ולא כותב cookies. |
| **Cache / localStorage** | הכלי לא משתמש ב-`localStorage`/`sessionStorage` ולא שומר תשובות במטמון. |

> הערות: (1) ה-salt ל-hash נשמר מקומית — ה-hash מונע שמירת טלפון בטקסט גלוי, אך אינו
> הגנה קריפטוגרפית חזקה מול תוקף שכבר יש לו גישה ל-GM storage (מרחב מספרי טלפון קטן).
> (2) Tampermonkey עצמו והדפדפן עשויים לתעד תעבורה ב-DevTools פתוח — זה מחוץ לשליטת הסקריפט.
